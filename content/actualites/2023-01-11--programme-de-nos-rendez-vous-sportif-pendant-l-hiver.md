Bonjour à tous,

Je tenais à vous souhaiter mes meilleurs vœux
en ce début d’année 2023 !

Comme je vous l'avais indiqué fin 2022, je
reviens vers vous concernant un programme d'activités sportives
que nous souhaitons mettre en place les mercredis après-midi.

Je vous explique ou réexplique comment ces
séances se dérouleront durant le cycle avant la reprise de l’école
de voile (le 22 mars). Le but de ces séances est non seulement de
garder le contact avec le côté convivial de toute l'équipe, mais
également de profiter d’une pratique sportive hebdomadaire en
dehors de l’école.

Je vous propose de se retrouver sur les
créneaux horaires habituels des mercredis (14h – 17h30).

**Attention**,
selon les dates, nous n’accueillerons que certaines tranches
d’âges pour des activités ciblées. Nos jeunes ont été séparés en 2
groupes distincts. D’une part les 2012 et plus (2012 ; 2013 ; … ;
2016) puis d’autre part les 2011 et moins (2011 ; 2010 ; 2009 ; …
).

Vous trouverez le programme des activités dans
le tableau ci-dessous :

|  |  |  |  |
| --- | --- | --- | --- |
| **Dates** | **Groupe** (années de naissance) | **Activités** | **Affaires à prendre** |
| Mercredi 25 janvier | Tout le monde | Randonnée | Vêtements de pluie si nécessaire |
| Mercredi 01 février | 2012 ; 2013 ;2014 ; 2015 ; 2016 | Parcours de motricité | Vêtements/chaussures de sport propre + eau |
| Mercredi 08 février | 2011 ; 2010 ; 2009 ; 2008 ; 2007... | Entretien Corporel | Vêtements/chaussures de sport propre + eau + serviette |
| Mercredi 15 février | Vacances scolaires (pas de séances prévues) | | |
| Mercredi 22 février |
| Mercredi 01 mars | Tout le monde | Piscine | Affaires de piscine |
| Mercredi 08 mars | 2012 ; 2013 ;2014 ; 2015 ; 2016 | Cirque | Affaires de sport |
| Mercredi 15 mars | 2011 ; 2010 ; 2009 ; 2008 ; 2007... | Sport collectif | Affaires de sport |
